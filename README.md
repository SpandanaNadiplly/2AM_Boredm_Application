# ⚡ I'M BORED AS HELL - The Ultimate Boredom Slayer

A modern, interactive, high-energy web application designed for people who have free time and want to create, learn, play, waste time pleasantly, or get things done with a companion AI chatbot.

## 🌟 Features

### 1. 🎨 CREATE HUB
- **Random Creative Challenges**: Design prompts (e.g. *"Design a logo for Moon Bean coffee"*), micro-stories, haiku battles, invention pitches.
- **15-Minute Circular Countdown Timer**: Progress ring animation and sound notifications.
- **Interactive Sketchpad Canvas**: Multi-color palette, brush controls, eraser, undo, and 💾 **Save Artwork as PNG**.

### 2. 🧠 LEARN HUB
- **50+ Mind-Blowing Facts & Rabbit Holes**: Science, nature, psychology, space, and history.
- **Text-to-Speech (TTS)**: Built-in audio narrator to read facts out loud.
- **AI Deep Dive**: Send topics straight to the AI companion for deep philosophical and technical discussions.

### 3. 🎮 PLAY HUB (Arcade Mini-Games)
- **🧩 Emoji Riddle Guesser**: Movies (`🧊 🚢 💔` = *Titanic*, `🎈 🤡 🌧️` = *It*), Games, Songs with hints, reveals, and streak tracking.
- **⌨️ Meteor Typer Game**: Space typing game with falling words, lasers, score tracking, and particle explosions.
- **⚡ Cyber Reflex Tester**: Millisecond reaction speed test with gamer rankings.

### 4. 💀 WASTE TIME HUB
- **🫧 Endless Bubble Wrap**: Satisfying tactile pop audio with a 💣 **Pop All** bomb mode.
- **🚨 The Forbidden Existential Button**: 50+ escalating reactions, witty insults, and screen shake physics.
- **🪨 Virtual Pet Rock**: Pet it, feed it virtual pizza, give it sunglasses, and read its geological thoughts.
- **🔊 Instant Meme Soundboard**: Procedural Web Audio synthesizers (Boom, Laser, Fanfare, Buzzer, Bubble, 8-Bit).

### 5. 🚀 BE PRODUCTIVE HUB
- **⏱️ 25-Min Focus Sprint (Pomodoro)**: Includes synthesized ambient audio (🌧️ Lo-Fi Rain, 🌌 Cyberpunk Drone, ☕ Cozy Cafe).
- **5-Minute Micro-Action Roulette**: Quick actionable wins to beat procrastination.

### 6. 🤖 BORED-BOT 9000 (AI Chat Companion)
- **5 Switchable Personas**: Sarcastic & Witty, Hype Beast 9000, Cosmic Philosopher, Dungeon Master RPG, and Smart Assistant.
- **Interactive Game Masters**: Plays **20 Questions**, runs branching **Text RPG Quests**, **Roast Me**, and **Debate Topics**.
- **Voice Support**: Voice input (Speech-to-Text) and audio responses (Text-to-Speech).
- **Dual Engine**: Works 100% offline out-of-the-box, with support for Google Gemini API or OpenAI keys for live LLM streaming.

## 🚀 Getting Started

No build tools or heavy installations required. Just clone and run:

```bash
# Clone the repository
git clone https://github.com/SpandanaNadiplly/2AM_Boredm_Application.git

# Navigate into the folder
cd 2AM_Boredm_Application

# Run with any local server (e.g. Python)
python3 -m http.server 3000
```

Open your browser and visit: `http://localhost:3000`
